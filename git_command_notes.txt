## Workflow ##
# do some work, then add something you worked on
git add filename.Rmd
# commit what you just added 
git commit -m "WIP"
# amend a commit since you're not done with the thing you're working on yet 
git add filename.Rmd
git commit --amend --no-edit
# make the final commit after you finished amending a bunch of times
git add filename.Rmd
git commit --amend -m "Implement awesome feature; closes #43"
# push (to remote)
git push
# remove a file?
git rm filename.txt # not sure this is right

## How to fix merge conflict ##
Open your terminal and navigate to your local repository. Pull the latest changes from the remote branch to trigger the conflict locally: git pull origin <branch-name>
Find the affected files by checking the Git status: git status
Open the files in a text editor (like VS Code). Look for the <<<<<<<, =======, and >>>>>>> markers. Clean up the code by choosing which lines to keep, then delete the marker lines entirely. 
Stage and commit your resolved files: 
git add "filename"
git commit -m "Resolve merge conflict"
Push the changes back to your GitHub repository: git push origin <branch-name>
